# Library API

OpenAPI 3.1 контракт сервиса «Библиотека»: книги, читатели и выдачи.

## Структура

- `openapi.yaml` — спецификация API.
- `STYLE.md` — правила оформления API.
- `REVIEW.md` — саморевью по чек-листу.
- `README.md` — этот файл.

## Ресурсы

- **Books** — книги: название, автор, ISBN, количество экземпляров.
- **Readers** — читатели: ФИО, email, дата регистрации.
- **Loans** — выдачи: кто, что и когда взял, когда вернул.

## Ключевые бизнес-правила

- Выдать книгу можно, только если `available_copies > 0`.
- У читателя не более 5 активных выдач.
- Возврат — через `POST /loans/{id}/return` (не DELETE).
- Удалить книгу/читателя с активными выдачами нельзя (409).
- `due_date` новой выдачи — строго в будущем.
- `available_copies` рассчитывает сервер: клиент его не передаёт.

## Идемпотентность

`POST /loans` требует заголовок `Idempotency-Key` (UUID).
Повтор с тем же ключом и телом — replay; другое тело — 409.
Ключ хранится 24 часа.
